Proyectos Académicos y Personales

En esta sección se presentan proyectos desarrollados en el ámbito académico y personal, demostrando la aplicación práctica de herramientas de desarrollo de software y bases de datos:

1. Sistema de Control y Registro de Pacientes (Escritorio)

Tipo: Proyecto Académico

Tecnologías utilizadas: C#, .NET Framework, Windows Forms, SQL Server

Descripción: Aplicación de escritorio diseñada para automatizar la gestión de consultas y el registro de información médica de pacientes. Permite registrar datos personales, agendar citas médicas y almacenar antecedentes clínicos en una base de datos centralizada.

Características principales:

  • Módulo de registro, edición y eliminación de pacientes (CRUD).
  • Búsqueda rápida por número de cédula y nombres.
  • Generación de reportes de visitas e historial de citas.
  • Validación de datos de entrada y control de usuarios.

2. Diseño de Base de Datos para Control de Inventario y Ventas

Tipo: Proyecto Académico

Tecnologías utilizadas: MySQL, SQL Server Management Studio (SSMS), Workbench

Descripción: Modelado relacional e implementación de una base de datos normalizada para gestionar compras, stock de productos, proveedores y transacciones de venta en un comercio minorista.

Características principales:

  • Diagrama Entidad-Relación y normalización hasta Tercera Forma Normal (3FN).
  • Creación de tablas con claves primarias, foráneas y restricciones de integridad.
  • Consultas complejas con sentencias JOIN, agrupamientos y funciones de agregación.
  • Vistas y procedimientos almacenados para actualización de inventario.
